Privacy & Support

What PG’s apps do with your information, how to check a download is genuine, and where to get help. This covers the released apps: Keepsake, Hangar, Verdant, Prism and Parley.

The Short Version

  • No trackingNo analytics, telemetry or crash reports, and nothing is ever sent to PG.
  • Only what the app needsEach app talks to the services it works with, such as Steam, NVIDIA or Discord, and to GitHub for updates. Nothing else.
  • Secrets stay encryptedHangar and Parley sign in with a QR code from your phone, so they never see your password, and the tokens they get back are encrypted with Windows’ own data protection (DPAPI).
  • This websiteNo analytics, no cookies and no third-party scripts. It’s hosted on GitHub Pages, which keeps its own server logs under GitHub’s privacy statement.

App by App

  • Keepsake Connects to Nintendo eShop and Steam store, SteamGridDB and GitHub
  • Hangar Connects to Steam, Steam Web API and GitHub
  • Verdant Connects to NVIDIA, Steam store and GitHub
  • Prism Connects to GitHub
  • Parley Connects to Discord, hCaptcha and GitHub

Each app’s page lists exactly what it connects to and why, what stays on your PC, and what it needs to run.

Checking a Download

Every app downloads from its own GitHub Releases page, and updates itself from there too, checking each download against its SHA-256 hash before installing.

The downloads aren’t code-signed yet, so Windows SmartScreen may say “Windows protected your PC” and that the publisher is unknown. Choose More info, then Run anyway. To check a download is the real one, compare its SHA-256 hash with the ones shown here. In PowerShell, run this on the file you downloaded:

Get-FileHash .\Keepsake_1.1.0_x64-setup.exe

The hash it prints should match the one in the Privacy & Security section of that app’s page, and the one GitHub shows next to the file.
