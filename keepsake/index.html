About

Keepsake is an emulator game manager and save editor for Windows. It brings the games and saves from ten emulators, including RPCS3, Lichii, Dolphin, Cemu and Vita3K, into one library with each game's artwork, starts any game in one click or from your controller in Big Picture, and edits the saves of five supported games in an editor built for each one. No hex editor, and a backup before every change.

Why Keepsake Exists

Every emulator keeps its games and saves its own way, in its own folders, and editing a save usually means a hex editor and offsets copied from a forum post.

Keepsake puts the games and saves from all your emulators in one library, starts any of them in one click, and turns supported saves into a form with the game's own artwork, with a backup before every change.

What Keepsake Does

  1. Every emulator, one library

    Keepsake finds the emulators you have and every game and save they keep, and shows each game with its own artwork from the Nintendo eShop, Steam or SteamGridDB. Press Play and the game starts straight away, without the emulator's game list.

  2. Your whole collection at a glance

    Games with saves come first, then everything else you own, labelled by platform. Keepsake also lists saves whose game it can't find, so nothing gets lost.

  3. Edit saves without a hex editor

    Each supported game gets an editor built for it and laid out like the game: studs, levels, collectibles, characters, vehicles and upgrades. Quick actions finish a chapter or unlock everything at once.

  4. With the game's own artwork

    Character portraits, shop icons and collectibles are read from your own copy of the game, so the editor looks like the game you're playing. Keepsake ships no game files.

  5. Saves from a real PS3, too

    Saves copied off a PlayStation 3 are encrypted and signed. Keepsake decrypts them so RPCS3 can use them, and the backup it takes first keeps the encrypted original.

Under the Hood

  • Saves from a real PS3Saves copied off a PS3 are encrypted and signed. Keepsake decrypts them with each game's secure file ID and writes them back plain for RPCS3. Re-encrypting and re-signing is kept too, and tested against real saves.
  • Reading Switch 2 save dataOcarina of Time on Switch 2 stores its save in Nintendo's GameData format, where every field name is a MurmurHash3 hash. Keepsake maps those hashes to rupees, hearts, items, songs and more, per save slot, and keeps the save's caption file in sync.
  • The game's own iconsSwitch games are encrypted, so Keepsake takes icons from the files your emulator already keeps: a game dump or a mod. It decodes the compressed archives and texture formats itself. Switch 2 lays texture bytes out differently from Switch 1, and that layout was worked out from real textures until every icon decoded cleanly.
  • Out of the way while you playKeepsake hands the memory it isn't using back to Windows while it's minimized, and won't write a save while that save's emulator is running, so a game in progress can never overwrite an edit or be overwritten by one.

Questions and Answers

Which emulators does Keepsake support?

RPCS3 (PlayStation 3), KytyPS5 (PlayStation 5), Vita3K (PlayStation Vita), Lichii and Fritchii (Switch and Switch 2), Cemu (Wii U), Dolphin (GameCube and Wii), Azahar (3DS), Mesen (NES, SNES and Game Boy) and mGBA (Game Boy Advance). PCSX2, PPSSPP and Xenia are coming.

Which games can Keepsake edit?

LEGO Batman: The Videogame, LEGO Indiana Jones: The Original Adventures and LEGO Pirates of the Caribbean on PS3, The Legend of Zelda: Ocarina of Time on Switch 2, and The Legend of Zelda: The Minish Cap on Game Boy Advance. Every other game still gets its saves listed, backed up and restored.

Does it work with saves from a real PS3?

Yes. Saves copied off a PlayStation 3 are encrypted and signed. Keepsake decrypts them with the game's own key so RPCS3 can use them, and the backup it takes first keeps the encrypted original.

Can editing a save break it?

Keepsake copies every save before it changes it, and before it restores a backup, so you can always go back from the Backups page. It also won't write a save while its emulator is running.

Is Keepsake free?

Yes. There are no ads, no accounts and no telemetry. If it saves you some time, you can support development on Ko-fi.

Does it need administrator rights?

No. The installer installs Keepsake for your Windows account only, and the portable keepsake.exe runs from any folder without installing.

Does Keepsake come with games or game files?

No. Keepsake works with the games and saves you already have. In-game artwork such as character portraits is read from your own copy of each game.

Why does Windows warn me when I run it?

Keepsake isn't code-signed yet, so Windows SmartScreen may say the publisher is unknown. Choose More info, then Run anyway. To check your download is the real one, compare its SHA-256 hash with the one in Privacy & Security below.

Privacy & Security

What it connects to

  • Nintendo eShop and Steam store: library artwork for your games
  • SteamGridDB: only if you add your own key, for more artwork
  • GitHub: to check for and download updates

What stays on your PC

  • Your games and saves are found, read and edited on your PC only
  • A backup of every save is kept on your PC before Keepsake changes it
  • In-game artwork is read from your own copy of each game
  • No analytics, telemetry or crash reports, and nothing is ever sent to PG.

Downloads and updates

  • Updates itself from its GitHub Releases page and checks each download against its SHA-256 hash before installing. You can turn this off under Settings › About.
